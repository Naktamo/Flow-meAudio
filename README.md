# Flow-meAudio
**Contextual Audio: From Static Playback to Intelligent Sound Environments:**   
Esse artigo trata de sistema sonoro que não somente segue, mas também verifica o contexto do local.
Resulmo:
"um que responde de forma inteligente ao espaço, tempo, comportamento do usuário e sinais ambientais. Nesse paradigma, o áudio passa a fazer parte do ambiente de vida, não uma tarefa de primeiro plano."
_https://www.ampvortex.com/contextual-audio-intelligent-sound-environments/_

**Follow-me audio: How KNX in smart homes is redefining multiroom AV:**  
Esse outro artigo tem o mesmo obejtivo. Contudo ele implementa a partir de sensores de presença, e com controladores de painel estático.
"Siga-me áudio vai além de ter alto-falantes em todos os quartos. Trata-se de criar um ambiente de som inteligente que responda à sua presença, atividades e preferências automaticamente - sem exigir um comando de voz. "

_https://www.knx.org/news/follow-me-audio-how-knx-smart-homes-redefining-multiroom-av_
